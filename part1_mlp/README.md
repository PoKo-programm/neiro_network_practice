# Часть 1. Объектно-ориентированная реализация многослойного перцептрона

Полносвязная нейронная сеть с одним (или более) скрытым слоем, реализованная на NumPy без использования готовых фреймворков.

## Состав

app/models.py — класс NeuralNetwork: инициализация весов, прямой и обратный проход, обучение мини-батчами, сохранение/загрузка весов.
app/manager.py — класс DatasetManager: загрузка CSV, нормализация (min-max или стандартизация), разбиение на train/test.
app/utils.py — парсинг пользовательского ввода.
app/main.py — консольное меню из семи пунктов.
app/exceptions.py — собственные исключения (реэкспорт из common).

## Запуск

Из корня репозитория:

python -m part1_mlp.app.main

## Пункты меню

1. Создать сеть (размеры слоёв, функция активации).
2. Загрузить данные из CSV (путь, метод нормализации).
3. Обучить сеть (learning rate, эпохи, размер батча).
4. Предсказание для одного или нескольких примеров.
5. Сохранить/загрузить веса в .npz.
6. Показать график ошибки (matplotlib).
7. Выход.

## Формат данных

CSV: первая строка — заголовки, последний столбец — целевая переменная (0/1). Остальные столбцы — числовые признаки. Пример: data/input/Social_Network_Ads.csv (400 строк, признаки Age и EstimatedSalary, цель Purchased).

## Архитектура

Пример для двух признаков и одного скрытого слоя из 4 нейронов: 2 → 4 → 1.

Инициализация: He для ReLU (sqrt(2/n_in)), Xavier для сигмоиды (sqrt(1/n_in)). Выходной слой — всегда сигмоида (бинарная классификация). Функция потерь — бинарная кросс-энтропия.

## Исключения

InvalidLayerSizeError — некорректные размеры слоёв или активация.
MismatchedDataError — несовпадение размерностей, нечисловой ввод.
DatasetFileError — ошибка чтения CSV.
UntrainedModelError — предсказание до обучения.
